Getting in should get them nothing.

Assume a breach is likely and design for it. The perimeter — passwords, locks, MFA, firewalls — matters and gets built well, but some door somewhere eventually fails: a phished credential, a lost laptop, a compromised vendor. So every design is judged by what an intruder finds when it does: material encrypted, access compartmentalized, nothing usable without keys they don't have, and a clear path back to normal. We don't sell "no one gets in". We sell "getting in gets them nothing".
